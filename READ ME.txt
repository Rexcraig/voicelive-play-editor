VoiceLive Play Editor v0.9 (test version)

The version is also shown next to "VoiceLive Play" at the top left of the editor. Mention it when you
report a problem.

Upgrading from an older version
Unzip the new version next to the old folder, not over it. Then copy sets.json, saves.json and the
backups folder from the old folder into the new one, so your sets and backups come with you.

Start
1. Plug the VoiceLive Play into this Mac with USB. Quit VoiceSupport if it's open.
2. Double-click "Start Editor".
   The first time, macOS may say it can't check the file. If so: right-click "Start Editor",
   choose Open, then Open again. The first start also installs what the editor needs (about a minute).
3. The editor opens in your web browser. Keep the Terminal window open while you use it.

Tabs
- Editor: shape a preset. The pedal plays every change straight away; it isn't kept until you save it.
  "Save to pedal" keeps it in a numbered preset.
- On the pedal: everything saved on the pedal. "Open in editor" to tweak one, or "Duplicate" to work on a
  copy: it opens under a new name with the first free preset number ready, so the original stays as it is.
- Sets: build a set list, song by song, then "Load onto pedal" to put it in order on the pedal.
- Setup: the pedal's own setup menu - input, outputs, tuner, foot switches - on one page instead of
  buried in the box. Changes go to the pedal when you pick them.
  Not sure what to pick? Press "Set up my rig", answer a few questions about your mic and cables, and it
  shows what it would change and why. Nothing changes until you press Apply.

The little i button
Next to a setting, it explains in plain words what that setting does and what to pick.
An amber i means the name isn't confirmed yet, so treat it as a guess.

If you hear no effects
Check Setup > Output. On MONO the pedal sends your dry voice out the LEFT socket and the effects out
the RIGHT one, so a single cable to the amp plays no effects. That was the problem on 17 September;
it is now set correctly, but it is the first thing to look at if effects go quiet again.

Safety
Whenever the editor replaces a preset, it first saves a copy in the "backups" folder next to this file.
To get one back: Files > Import presets, pick the backup, then Save to pedal.
